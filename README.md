# Mohammed Safouane Medjahri

AI and Data Science engineering student at ESI-SBA, Oran, Algeria. I build end to end
machine learning: data preparation, modelling, evaluation, and the pipeline that keeps the
model running once the notebook is closed.

Currently in my final year, looking for a PFE or a research internship.

## What I work on

- **Computer vision.** Segmentation, detection and character recognition on scanned and
  photographed documents.
- **Speech and language.** Speech to text, speech emotion recognition and lexical pipelines.
- **Tabular ML and MLOps.** Gradient boosting and ensembles, experiment tracking, model
  registries, drift monitoring and retraining loops.

## Selected projects

| Project | What it does |
| --- | --- |
| [h-gate](https://github.com/S4afou/h-gate) | Multi-class malicious URL detection. Stacked FT-Transformer, LightGBM, XGBoost and CatBoost, tuned with Harris Hawks Optimization. Macro-F1 0.9856. |
| [spell-caster](https://github.com/S4afou/spell-caster) | Dual-task ASR and speech emotion recognition for a voice-driven spellcasting game. Whisper-Small with LoRA, a Conformer baseline, ONNX INT8 and a FastAPI server. |
| [eigenfaces-fisherfaces](https://github.com/S4afou/eigenfaces-fisherfaces) | Classical face recognition on Olivetti Faces. PCA component sweeps, 1-NN against a linear SVM, noise robustness and cross-validation. |
| [adain-style-transfer](https://github.com/S4afou/adain-style-transfer) | From-scratch AdaIN arbitrary style transfer. Frozen VGG-19 encoder, trained decoder, about 150 ms per 512x512 image. |
| [shuttle-nasa-ML](https://github.com/S4afou/shuttle-nasa-ML) | Anomaly detection on NASA shuttle telemetry, with a Streamlit diagnostic panel. |
| [shuttle-nasa-mlops](https://github.com/S4afou/shuttle-nasa-mlops) | The MLOps loop around that detector: data versioning, sweeps, model registry, drift monitoring and retraining. |
| [olympics-dashboard](https://github.com/S4afou/olympics-dashboard) | Four-page Streamlit dashboard on the Paris 2024 Olympic Games dataset. |
| [pocket-omr](https://github.com/pocket-omr) | Answer sheet grading from a phone photo. Pluridisciplinary project, six students: rectification, segmentation, bubble reading and handwriting recognition. |
